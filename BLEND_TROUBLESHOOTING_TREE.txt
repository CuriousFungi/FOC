VERIFICATION CHECKLIST
================================================================================

Before diving into troubleshooting, verify basics:

☐ Motor can run in pure open-loop (blend = 0.0 manually forced)
☐ Motor can run in pure closed-loop (blend = 1.0 manually forced)
☐ Encoder is reading position (g_as5048_angle updating)
☐ Kalman velocity estimate is working (g_kalman_velocity reasonable)
☐ Target speed is above transition threshold (> 20 rad/s)
☐ Code compiles without warnings
☐ All debug variables are visible in STM32CubeMonitor

If any of the above fail, fix those FIRST before debugging blend!


================================================================================
ADVANCED DEBUGGING
================================================================================

For complex issues, add these temporary debug variables:

1. Raw angle difference:
   volatile float g_debug_angle_diff =
       g_closed_loop_elec_before_blend - g_open_loop_elec_before_blend;

2. Unwrapped angles (after wraparound correction):
   volatile float g_debug_unwrapped_open;
   volatile float g_debug_unwrapped_closed;

3. Blend calculation breakdown:
   volatile float g_debug_open_contribution =
       (1.0f - blend_factor) * open_loop_electrical;
   volatile float g_debug_closed_contribution =
       blend_factor * closed_loop_electrical;

4. Rate limiter details:
   volatile float g_debug_angle_change_raw;
   volatile float g_debug_angle_change_clamped;
   volatile bool g_debug_rate_limit_hit;


================================================================================
FINAL NOTES
================================================================================

Most Common Causes:
1. Speed not reaching threshold (50% of cases)
2. Encoder offset wrong (30% of cases)
3. Kalman filter instability (15% of cases)
4. Code bugs (5% of cases)

Most Effective Solutions:
1. Lower speed thresholds to 5-15 rad/s
2. Recalibrate encoder during alignment
3. Add hysteresis (±2 rad/s) to thresholds
4. Verify all angles in same reference frame

When All Else Fails:
1. Force blend_factor = 0.5 manually
2. Observe motor behavior at fixed blend ratio
3. Gradually adjust blend and find stable region
4. Use that as new threshold values

Remember: The blend mechanism is working in your code RIGHT NOW!
You just need to visualize it and tune the parameters. 🎯
