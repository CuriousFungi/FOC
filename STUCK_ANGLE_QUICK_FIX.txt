================================================================================
WHY THIS HAPPENS
================================================================================

The code has an early return that exits update_speed_closed_loop() if
the target speed is below 0.0001 rad/s:

  if (actual_target_rps < 0.0001) return;

The ramped_speed starts at 0.001 rad/s and increments by:
  ACCEL_RATE × delta_seconds = 1.0 × 0.001 = 0.001 rad/s per iteration

During startup, ramped_speed hovers around the epsilon threshold (0.0001),
causing the early return to trigger repeatedly.

When the early return executes:
  - Blending code never runs
  - Angle variables never update
  - Last valid angle (4.82 rad) remains frozen
  - Motor commutates at FIXED angle → terrible performance

SOLUTION: Ensure ramped_speed starts ABOVE epsilon or disable the check.
