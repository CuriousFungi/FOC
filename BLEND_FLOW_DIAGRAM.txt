================================================================================
ANGLE BLENDING EXAMPLE
================================================================================

Scenario: Speed = 15 rad/s (middle of transition)

Step 1: Calculate blend_factor
   blend_factor = (15 - 10) / (20 - 10) = 0.5

Step 2: Get both angles
   open_loop_angle   = 1.2 rad  (from accumulation)
   closed_loop_angle = 1.3 rad  (from encoder)

Step 3: Check for wraparound
   diff = 1.3 - 1.2 = 0.1 rad
   |diff| < π, so no wraparound correction needed

Step 4: Blend
   blended = (1 - 0.5) × 1.2 + 0.5 × 1.3
           = 0.5 × 1.2 + 0.5 × 1.3
           = 0.6 + 0.65
           = 1.25 rad

Step 5: Rate limit (if needed)
   prev_angle = 1.20 rad
   angle_change = 1.25 - 1.20 = 0.05 rad
   |0.05| < 0.5 (max), so no limiting needed
   final_angle = 1.25 rad

Result: Motor commutates at 1.25 rad electrical angle


================================================================================
WRAPAROUND HANDLING EXAMPLE
================================================================================

Scenario: Angles near 0/2π boundary

Before correction:
   open_loop_angle   = 0.1 rad  (just past zero)
   closed_loop_angle = 6.1 rad  (just before 2π ≈ 6.28)

Step 1: Calculate difference
   diff = 6.1 - 0.1 = 6.0 rad

Step 2: Check if wraparound
   diff > π (3.14), so wraparound detected!

Step 3: Unwrap angle
   closed_loop_angle -= 2π
   closed_loop_angle = 6.1 - 6.28 = -0.18 rad

Step 4: Now blend smoothly
   blend_factor = 0.5
   blended = 0.5 × 0.1 + 0.5 × (-0.18)
           = 0.05 - 0.09
           = -0.04 rad

Step 5: Normalize back to [0, 2π)
   final_angle = -0.04 + 6.28 = 6.24 rad

Result: Smooth blending across boundary, no discontinuity!
